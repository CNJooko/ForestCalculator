## 3. 审计结论

### 3.1 新系统相对于旧系统的改进

| 维度 | 旧系统 (scaleBySpecies) | 新系统 (econBasePct) |
|------|------------------------|---------------------|
| **透明度** | 暗箱缩放，无法审计 | 每树种显式基准值，可追溯 |
| **可追溯性** | 无文档记录缩放逻辑 | 基准值标注林学依据 |
| **树种独立** | 全局缩放因子混用 | 逐树种独立 econBasePct |
| **来源标注** | 无 | 各树种标注来源标准 |
| **D/H 调整** | 不可见 | 线性公式: base + 0.18(D-20) + 0.34(H-15) |
| **裁剪策略** | 65-90% | 扩大至 50-92%，减少边界撞墙 |
| **覆盖率** | 部分树种 | 全部 23 树种 |

### 3.2 潜在风险与建议

1. **斜率参数来源单一**: 当前 D/H 敏感性斜率 (+0.18%/cm, +0.34%/m) 仅来自
   DB51/T 1466 马尾松 153 点回归 (R²=0.977)。其他树种 (尤其是阔叶类) 的
   出材率随径级变化规律可能不同，但当前均使用同一斜率。

2. **硬阔树种可能高估**: 硬阔 (econBasePct=65) 使用默认阔叶 yieldRates，
   但其实际出材率可能更低。建议获取贵州 DB52/T 826 硬阔出材率表进一步校准。

3. **福建树种缺 econBasePct**: 福建 4 树种均未定义 econBasePct，使用默认 75%。
   建议参照 DB35/T 1823 补充。

4. **默认值 75% 的使用**: 以下 4 个树种使用默认值，缺少树种特异性验证：
   - 杉木(福建·2019) (DB35/T 1823-2019 福建省主要树种二元立木材积表)
   - 马尾松(福建·2019) (DB35/T 1823-2019 福建省主要树种二元立木材积表)
   - 阔叶树(福建·2019) (DB35/T 1823-2019 福建省主要树种二元立木材积表)
   - 其他针叶(福建·2019) (DB35/T 1823-2019 福建省主要树种二元立木材积表)

### 3.3 审计总结

新系统在透明度、可追溯性、树种独立性方面显著优于旧系统。
马尾松敏感性验证通过 (单调递增、裁剪范围内、斜率接近 DB51/T 1466)。
建议优先为 4 个默认值树种获取实测出材率数据，逐步消除默认值依赖。
